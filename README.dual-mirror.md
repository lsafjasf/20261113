# 双镜台 · DUAL MIRROR

双人同屏合作的射电望远镜仪表盘小游戏。两名玩家共控一台望远镜，在风暴前锋抵达、
电池耗尽之前锁定三个真正的异常信号。

## 玩法

- 左玩家：`A / D` 调方位，`W / S` 调接收增益。
- 右玩家：`↑ / ↓` 调仰角，`,` / `.` 切换滤波频段（L / S / X）。
- 当方位与仰角**同时**落入目标容差（方位 ±8°、仰角 ±6°）并持续 **2 秒**，信号锁定。
- 真异常是雷达上的双峰（绿），诱饵是单峰（红）；错锁两次诱饵任务立即失败。
- 信号按固定节律闪烁，保持期间信号熄灭会中断并重置 2 秒计时。
- 高增益能收到弱信号，但底噪更大、耗电更快；电池归零或局时（110 秒）结束即失败。
- 风暴持续把两轴推离中心，阵风前会在右上角弹出推力预报，两侧必须同时纠正。
- 一方的轴失谐会污染另一方看到的频谱瀑布（方位失谐污染右镜，仰角失谐污染左镜）。

每局使用固定 seed（`20261113`）生成同一张雷达屏：3 个真异常 + 2 个诱饵，
位置、频段、所需增益、闪烁节律完全可复现。

## 单人调试开关

开场简报左下角的「单人调试」勾选后：

- 顶部模式明确标注为「单人调试 · 非正式记录」，并出现琥珀色调试徽标；
- 左下角提供可按住的屏幕按钮，模拟两侧全部按键与阵风暂停；
- 雷达左上角叠加各信号的频段 / 增益数值辅助。

不勾选时即为「双人同屏 · 正式合作」模式，只能用键盘双人操作。

## 运行

```bash

python3 -m http.server 8791

```

## 代码结构

- `src/constants.js`：全部平衡性常量与角度工具。
- `src/rng.js` / `src/signals.js`：确定性随机数与固定 seed 的信号生成、闪烁判定。
- `src/engine.js`：纯逻辑引擎（状态、输入、风暴、电池、双轴锁定、胜负判定），不依赖 DOM。
- `src/input.js`：双人键盘同时输入，失焦自动松键，`,` / `.` 边沿切频段。
- `src/audio.js`：Web Audio，左右声道分别提示方位 / 仰角，频段改变音色。
- `src/draw/`：Canvas 雷达 PPI、方位刻度、仰角表、增益 / 电平条、双侧频谱瀑布。
- `src/main.js`：界面装配、HUD 刷新、通告流与结算屏。
- `test/`：Node 引擎测试与 Playwright 端到端验证。

## 验证

```bash
npm test          # 引擎与瀑布的 Node 单元测试（11 项）
npm run test:e2e  # Playwright 端到端（自带静态服务器，17 项断言）
```

端到端覆盖要求的全部路径：

1. 同时按住两侧按键完成一次方位 + 仰角协同校正并锁定；
2. 增益拉满空转直到电池耗尽，出现「电池耗尽」失败结算；
3. 依次锁定三个真异常，出现「三个异常全部锁定」胜利结算；
4. 连续错锁两个诱饵，出现「任务无效」失败结算；
5. 调试模式有清晰的非正式标注。

无头环境若缺少浏览器系统库或中文字体，可参考：

apt-get download libnspr4 libnss3 libasound2t64 fonts-noto-cjk
